Thank you for installing PostgreSQL.

Release Information
-------------------
Release Name : {{ .Release.Name }}
Namespace    : {{ .Release.Namespace }}
Chart        : {{ .Chart.Name }}
Version      : {{ .Chart.Version }}

Check PostgreSQL Resources
--------------------------
kubectl get all -n {{ .Release.Namespace }}

Check the Pod
-------------
kubectl get pods -n {{ .Release.Namespace }}

Check the Service
-----------------
kubectl get svc -n {{ .Release.Namespace }}

Check the Persistent Volume Claim
---------------------------------
kubectl get pvc -n {{ .Release.Namespace }}

View Pod Logs
-------------
kubectl logs -f deployment/{{ include "postgres.fullname" . }} -n {{ .Release.Namespace }}

{{- if .Values.statefulset.enabled }}

If using StatefulSet
--------------------
kubectl logs -f statefulset/{{ include "postgres.fullname" . }} -n {{ .Release.Namespace }}

{{- end }}

Describe the Deployment
-----------------------
kubectl describe deployment {{ include "postgres.fullname" . }} -n {{ .Release.Namespace }}

Database Connection
-------------------
Host     : {{ include "postgres.fullname" . }}
Port     : {{ .Values.service.port }}
Database : {{ .Values.config.POSTGRES_DB }}

Port Forward (for local testing)
--------------------------------
kubectl port-forward svc/{{ include "postgres.fullname" . }} 5432:{{ .Values.service.port }} -n {{ .Release.Namespace }}

Then connect using:

Host     : localhost
Port     : 5432
Database : {{ .Values.config.POSTGRES_DB }}
Username : <POSTGRES_USER>
Password : <POSTGRES_PASSWORD>

Helm Commands
-------------
Upgrade:
helm upgrade {{ .Release.Name }} . -n {{ .Release.Namespace }}

Rollback:
helm rollback {{ .Release.Name }} 1 -n {{ .Release.Namespace }}

Uninstall:
helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}

Happy Deploying!
